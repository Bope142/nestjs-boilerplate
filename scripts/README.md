# Scripts

| Script | Purpose |
|--------|---------|
| `setup.mjs` | First-time setup: `.env`, Git hooks, next steps |
| `init-project.mjs` | Rename package and patch env defaults |
| `install-git-hooks.mjs` | Configure `core.hooksPath` |
| `seed-users.ts` | Seed super admin (`pnpm db:seed`) |

Run via `pnpm setup`, `pnpm init:project`, or `pnpm hooks:install`.
